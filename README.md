# ELA
DEPI TEAM 4 PROJECT
1. Project Name:
ELA – حملة تسويقية لعلامة تجارية مصرية متخصصة في منتجات العناية الشخصية الطبيعية.
2. Project Idea:
إنشاء حملة تسويقية متكاملة باستخدام أدوات الذكاء الاصطناعي لبراند ELA، بهدف التوعية بالمكونات الطبيعية، ومساعدة الجمهور على اختيار منتجات وروتين العناية المناسب، وزيادة الوعي بالبراند والترويج لمنتجاته.

4. Work Plan:
تحديد الجمهور المستهدف واحتياجاته.
دراسة البراند وتحليل المنافسين.
إعداد الاستراتيجية التسويقية والمحتوى.
تطوير الأفكار الإبداعية وكتابة السيناريوهات.
إنتاج الصور والفيديوهات باستخدام أدوات AI.
المونتاج وإضافة المؤثرات الصوتية والبصرية.
تجهيز وتسليم الحملة والعرض النهائي.
5. Roles & Responsibilities:
التسويق والاستراتيجية: دراسة السوق والمنافسين وتحديد الجمهور والتمركز الذهني.
صناعة المحتوى: إعداد الأفكار الإبداعية ومحاور المحتوى وكتابة السيناريوهات.
الإخراج الفني والتصميم: تحديد التوجه البصري وتصميم المواد الإعلانية.
إنتاج محتوى AI: توليد الصور والفيديوهات والتعليق الصوتي باستخدام أدوات الذكاء الاصطناعي.
المونتاج: تحرير الفيديوهات وإضافة الموشن جرافيك والمؤثرات الصوتية.
نعمل جميعا بالتبادل على المشروع بشكل منتظم
6. KPIs:
معدل التفاعل (Engagement Rate).
مدى الوصول والوعي بالبراند (Reach & Brand Awareness).
عدد مشاهدات الفيديوهات (Video Views).
تفاعل الجمهور مع المحتوى.
مدى وضوح وتذكر الرسالة التسويقية.

 ايهاب العبيد
8. Project Files
استراتيجية البراند والهوية البصرية.
